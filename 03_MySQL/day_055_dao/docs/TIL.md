## 목차

## VO, DAO

### VO (Value Object)

- 특정 테이블의 한 행을 매핑하는 클래스

| 테이블      | 컬럼들 | 한 행    |
| ----------- | ------ | -------- |
| 클래스 정의 | 필드들 | 인스턴스 |

> [TIPS] JPA 사용하는 경우 VO 객체가 JPA의 라이프 사이클과 일치 됨
>
> - VO를 직접 수정하면 안됨
> - VO 객체와 DTO를 엄격하게 분리 해야 함

### DAO (Data Access Object)

- 데이어베이스에 접근하여 실질적인 데이터베이스 연동 작업을 담당하는 클래스
- 테이블에 대한 CRUD 연산을 처리
- 인터페이스 정의 후 구현 클래스 작성함
