## 테이블

### 제약조건 (Constraint)

- 데이터 무결성을 지키기 위한 제한된 조건
- PRIMARY KEY
- FOREIGN KEY
  - ON DELETE(UPDATE) CASCADE
  - 기존키 변경시 외래키 자동 적용
- UNIQUE
  - NULL 여러개 입력 허용
- CHECK
  - 입력되는 데이터를 점검
  - check (birtyYear >=1900 AND birthYear <=2026)
- DEFAULT 정의
  - 값 입력 안했을 때 자동 입력되는 기본 값
- NULL 허용

### 테이블 삭제

- DROP TABLE
- 외래 키 제약 조건의 기준(원본) 테이블 삭제할 수 없음
  - 외래키 테이블을 먼저 삭제해야함

### 테이블 수정

- ALTER TABLE
  - 열 추가
    - ADD
  - 열 삭제
    - DROP COLUMN
    - 제약조건이 존재한다면 제약 조건을 먼저 삭제해야 함
      열 수정
    - CHANGE COLUMN <원래 이름> <새 이름> <제약조건>

## 뷰

### 뷰의 개념

- 물리적으로 존재하지 않는 테이블
- 일반 사용자 입장에서 테이블과 동일하게 사용하는 개체
- INSERT, UPDATE, DELETE 가능하나 대부분 제약조건에 의해 실패할 가능성 높음
  - 선택된 컬럼에만 접근 가능하기 때문
  - SELECT만 거의 함
- 긴 쿼리를 뷰로 작성해 단순화 됨

### 뷰 명령어

```sql
create view 뷰이름A as (
SELECT FROM 구문);
```

## 인덱스

| 장점                  | 단점                                                               |
| --------------------- | ------------------------------------------------------------------ |
| 검색 속도 향상        | 추가 공간 필요                                                     |
| 시스템 전체 성능 향상 | 데이터 변경작업(insert, update, delete) 많이 일어날 경우 성능 저하 |

- `SHOW INDEX FROM tbl;` 로 인덱스 확인 가능

### 인덱스 종류

1. 클러스터형 인덱스
   - 행 데이터를 자신의 열을 기준으로 정렬
   - 테이블 당 하나만 생성 가능
2. 보조 인덱스
   - 별도의 공간을 추가해 지정한 컬럼만 정렬
   - 여러개의 인덱스 생성 가능

### 인덱스의 자동생성

- PRIMARY KEY
  - 클러스터형 인덱스 자동 생성
- UNIQUE
  - 보조 인덱스 자동 생성
- PRIMARY KEY 없고, UNIQE NOT NULL 존재한다면
  - 클러스터형 인덱스로 생성

### 인덱스 명령어

```sql
CREATE [UNIQUE|FULLTEXT|SPATIAL] INDEX 인덱스명 ON 테이블명(컬럼명 , ...);
DROP INDEX 인덱스명 ON 테이블명;
```

---

| 종류     | 핵심 목적        | 주요 사용처    |
| -------- | ---------------- | -------------- |
| UNIQUE   | 중복 방지        | 아이디, 이메일 |
| FULLTEXT | 텍스트 검색      | 게시글, 본문   |
| SPATIAL  | 공간 데이터 검색 | 지도, 좌표     |

## 사용자 권한

### 사용자 관리

- 관리자 권한으로 사용할 경우 보안에 취약하므로 사용자를 통해 DB 관리해야 함
- 사용자 추가
  - `CREATE USER '사용자명@호스트명' IDENTIFIED BY '비밀번호';`
- 사용자 삭제
  - `DROP USER '사용자명@호스트명'`
- 사용자 접속 호스트 제한 풀기
  - 호스트명에 '%' 지정

### 권한 관리

- `GRANT ALL PRIVILEGES ON 데이터베이스명.객체 TO '사용자명@호스트명';`
  - 모든 객체 지정하려면 : `데이터베이스명.*`
  - 호스트명에는 접속 위치 지정 가능하며 '%' 지정시 제한 없음
- 권한 설정 적용하기 : `FLUSH PRIVILEGES;`
