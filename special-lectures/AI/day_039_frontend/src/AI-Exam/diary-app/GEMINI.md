# Project: Vue3 Diary App

## Tech Stack

### Frontend

- Framework: Vue 3 ( Vite
- API Style: Composition API (<script setup>)
- Styling: Bootstrap5
- State Management: Pinia (Local Storage 저장)
- Icon Font: FontAwesome5

### Backend

- Framework: json server@v1.0.0 beta.15
- 데이터 양식 : json
- 데이터 파일명 : db.json

## Instructions

- 모든 컴포넌트는 SFC 스타일로 작성해줘
- 변수명은 camelCase, 파일명은 PascalCase 를 사용해줘
- 일기 데이터는 로컬 스토리지를 활용해서 영구 저장되게 해줘
- 작성한 코드에 대해 한글로 주석설명 해줘
- 타이틀 , 레이블 , 버튼 , 링크를 만들 때 어울리는 FontAwesome 5 아이콘을 붙여줘
